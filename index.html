For teachers: how this unit was made

  1. Each lesson was described to an AI assistant in plain English and came back as one HTML file.
  2. The four files and this home page sit together in one folder.
  3. The folder was uploaded to GitHub and published with GitHub Pages, so the whole unit has one link.
  4. To add a lesson, upload one more HTML file and add one card to this page.
